# Détecteur de mouvement à code

Projet final du cours 420-314 Plateformes embarquées (automne 2026), sur Arduino Nano ESP32 en MicroPython.

## Membres

- Wassim
- Hussein

## Description

Le système surveille une pièce. Dès qu'il détecte un mouvement ou que l'aimant de la porte se détache, le buzzer sonne. Pour l'arrêter, il faut entrer le bon code à 4 chiffres avec un potentiomètre et un bouton, en moins de 50 secondes et avec 5 essais au maximum. L'écran LCD affiche le temps et les essais qui restent, ainsi qu'un indice après chaque essai raté.
